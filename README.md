# ImAHungover Homebrew tap

Homebrew casks for [OpenFortiClient](https://github.com/ImAHungover/open-forti-client), an open-source client for Fortinet SSL-VPN gateways on macOS.

```sh
brew install --cask imahungover/tap/openforticlient
```

After installing, open the app, go to Settings → Privileged helper → Install, and allow it in System Settings → General → Login Items.

Uninstall with `brew uninstall --cask openforticlient`; add `--zap` to also remove settings, connections and logs. Saved passwords stay in the Keychain.

The cask is generated by [`scripts/make-cask.sh`](https://github.com/ImAHungover/open-forti-client/blob/main/scripts/make-cask.sh) for each release.
